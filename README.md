# Knight's Travails

A `knightMoves` function that finds the shortest path a knight can take between two squares on a standard 8x8 chessboard, using breadth-first search.

## Getting Started

Clone the repo:
```bash
git clone https://github.com/OverlordGummyBear/knight-travails.git
cd knights-travails
```

## Running It

```bash
node knight-travails.js
```
